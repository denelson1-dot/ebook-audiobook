Pronunciation fixes — words the narrator says wrong

Narrators mispronounce names and invented words, and often read an acronym as separate letters — “en ay ess ay” instead of “nassa”. Write the word as the book spells it, then how it should sound — one per line:

Ryland = Rye-land Xenonite = Zee-non-ite NASA = Nassa
  • Spell the right-hand side how it sounds, not how it is spelled. Hyphens between syllables help; the narrator reads it as ordinary words.
  • Whole words only — Grace never changes Graceful.
  • Typed exactly, capitals and all. A fix written NASA changes NASA and leaves nasa alone — so fixing an acronym never touches an ordinary word spelled the same way.
  • Only the sections containing that word are narrated again, so a fix costs minutes, not hours.
  • Generate a preview of a section that uses the word to hear whether it worked.
